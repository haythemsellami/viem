# Monad

## Overview

The `viem/monad` module implements the proposed Monad universal transaction envelope, type `0x40`. It provides canonical encoding, decoding, ECDSA signing, and hashing through `Transaction`, plus opt-in [RPC integration](/docs/monad/rpc) for the existing sender-paid baseline.

Transactions contain a chain identifier and an ordered feature list. Decoding preserves unknown feature values as RLP byte strings or lists. Signing requires the supported cleartext baseline, so an unknown feature cannot silently change what a signer approves.

```ts twoslash
import { Transaction } from 'viem/monad'

const transaction = Transaction.from({
  chainId: 143,
  nonce: 7n,
  gas: 21_000n,
  to: '0x0000000000000000000000000000000000000001',
  value: 1_000_000_000_000_000_000n,
  maxPriorityFeePerGas: 2_000_000_000n,
  maxFeePerGas: 50_000_000_000n,
})
const serialized = Transaction.serialize(transaction)
// @log: '0x40...'
```

This module targets the draft's main encoding. Network submissions add an empty auxiliary list; nonempty auxiliary data, batching, and sponsorship are unsupported. The example gas limit is illustrative; it does not establish intrinsic gas cost or network availability.
